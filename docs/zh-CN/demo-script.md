# 两分钟演示提纲

> 本文是 [Two-minute demo outline](../demo-script.md) 的中文翻译。

## 0–15 秒：任务与基线

- 展示不包含身份信息的目标仓库窗口。
- 运行已有单元测试，并展示可确定复现的失败。
- 直接运行 `coding-agent` 进入终端会话。
- 如果演示首次运行时的初始化流程，展示生成的忽略规则和初始提交，但不要暴露本地路径或个人身份。

## 15–30 秒：架构

只展示下面这条控制路径：

```text
CLI -> AgentEngine <-> Model
                -> Policy -> Local tools -> Workspace
                <- Tool results and verification evidence
```

## 30–85 秒：真实循环

- 在 `coding-agent>` 提示符下提交任务。
- 展示简洁的事件：读取、搜索、哈希保护编辑、验证命令。
- 可以加速等待过程，但不要隐藏输入或结果。

## 85–105 秒：证据

- 展示最终 Git 差异。
- 展示通过的验证以及当前工作区版本。
- 只有在完成门禁接受证据后，才展示 `SUCCEEDED`。

## 105–120 秒：设计主张

说明模型负责提出动作，而控制器负责权限、执行、重试、预算和终止状态。明确说明当前版本提供的是工作区级控制，而不是操作系统沙箱。

## 录制卫生要求

- 使用不包含身份信息的终端提示符和工作目录；
- 不出现账户头像、浏览器会话、通知或个人书签；
- 不出现姓名、学校、邮箱、Git 身份或本地绝对路径；
- 不出现 API 密钥、环境变量转储或原始模型请求；
- 录制前检查仓库文件和提交元数据。
