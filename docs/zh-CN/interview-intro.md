# 一分钟英文介绍（中文参考译文）

> 本文是 [One-minute English introduction](../interview-intro.md) 的中文参考译文；面试时应使用英文原文。

我构建了一个面向本地 Git 仓库、由控制器驱动的编程智能体。模型负责提出动作，但整个过程由我实现的控制器管理。每一轮只接受一个动作；如果供应商返回多个工具调用，适配器只执行第一个。控制器负责校验权限、运行本地文件和命令工具、记录真实结果，并把结果送入下一轮。带哈希保护的编辑可以防止过期内容被覆盖。命令执行需要用户审批，不经过 Shell，而且永远不会获得模型 API 密钥。模型只能请求结束任务；只有当前工作区版本具备最新验证证据时，控制器才会接受这个请求。我还实现了可恢复的上下文、离线测试，以及通过隐藏测试检测虚假成功的独立评测框架。
