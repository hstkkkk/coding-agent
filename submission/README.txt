项目名称：Bounded Coding Agent

仓库地址：<提交前填写匿名公开仓库地址>

运行环境：Python 3.11+、Git，以及支持原生 tool calling 的 OpenAI-compatible 模型接口。安装命令为 `python -m pip install -e .`。设置 `OPENAI_API_KEY`、`CODING_AGENT_MODEL` 后，运行：`coding-agent run --workspace <Git仓库路径> "<编程任务>"`。默认情况下，命令执行与文件删除需要人工确认。离线测试：`python -m unittest discover -s tests -v`。

核心特色：系统自行实现单智能体闭环，模型每轮只能提出一个结构化动作；本地控制器掌握参数校验、权限、工具执行、错误分类、预算和停止条件。文件编辑采用哈希前置条件，防止旧上下文覆盖新修改；子进程不继承模型密钥；工具输出经过限长、脱敏和事件记录。模型只能申请完成，控制器仅在当前工作区版本具备成功验证证据并能检查最终 Git diff 时接受。项目还提供隔离评测工具，可在临时仓库中运行任务，并通过智能体不可见的测试独立检查结果及虚假成功。

已知限制：当前版本不提供操作系统级沙箱、断点恢复、多智能体协作或大仓库索引；经批准的仓库代码仍以当前用户权限运行。
